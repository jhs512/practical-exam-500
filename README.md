# 정보처리기사 실기 500

휴대폰으로 틈틈이 푸는 자체 제작 객관식 연습문제 500개입니다. 공식 기출 원문 모음이 아닙니다.

[문제 풀기](https://jhs512.github.io/practical-exam-500/)

- 매번 무작위 문제와 섞인 보기 10개 이상을 제시합니다.
- 보기를 누르면 바로 채점하고 정답과 단계별 풀이, 보기별 해설을 보여줍니다.
- 맞힌 문제는 출제에서 빠지고, 틀린 문제는 다시 나옵니다.
- ‘다시 만나기’를 켜면 맞힌 문제도 복습할 수 있습니다.
- 기록은 현재 브라우저에 저장됩니다. 초기화는 이 앱의 기록만 지웁니다.

## 구성

요구사항 21, 데이터 입출력 43, 통합 6, 서버 30, 인터페이스 11, 화면 9, 테스트 41, SQL 47, 보안 51, 언어 149, 기초 기술 84, 패키징 8문항입니다. 이 배분은 편집상의 선택이며 공식 출제 비중을 뜻하지 않습니다.

언어 문제는 C 65, Java 45, Python 39문항입니다. SQL 결과와 언어 실행 결과는 실제로 실행해 확인합니다. 이론·모델 기반 계산 문항은 자동 생성 검사와 표본 의미 검토를 거칩니다.

## 실행과 검증

Node.js와 Python 3.10 이상이 필요합니다. 문항을 다시 생성할 때는 JDK와 `pip install ziglang`도 필요합니다.

```sh
npm ci
npm run serve
```

브라우저에서 `http://localhost:4573/practical-exam-500/`을 엽니다.

```sh
npm run build
npm run test:unit
python tests/check_published_sql.py
npx playwright install chromium
npm run test:e2e
```

실제 운영 주소를 검사하려면 `BASE_URL`을 사이트 주소로 설정하고 브라우저 검사를 실행합니다. 생성 대상과 영역별 문항 수는 `gen/release.py`에서 관리합니다. 공개 데이터는 `site/data/`에 있고, 비공개 참조 자료는 포함하지 않습니다.
